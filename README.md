# Khun Mhee · Pet Friendly House

เว็บไซต์จองห้องพัก (GitHub Pages) เชื่อมกับระบบหลังบ้าน Google Apps Script + Google Sheets และแจ้งเตือนแอดมินทาง LINE

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก แสดงราคาห้องจริงจากแท็บ Rooms |
| `booking.html` | จองห้อง: เลือกห้องและวัน (ดูวันว่างจริง) → ข้อมูลผู้เข้าพัก → ชำระเงินและแนบสลิป → รออนุมัติ |
| `login.html` | เข้าสู่ระบบแอดมิน (ใช้บัญชีในแท็บ Users) |
| `admin.html` | แดชบอร์ดแอดมิน: อนุมัติ/เช็คอิน/เช็คเอาท์/ยกเลิก ดูสลิป ส่งอีเมลเตือนลูกค้า ทดสอบ LINE |
| `js/config.js` | **ที่ต้องแก้:** URL ของ Apps Script และรูปของแต่ละห้อง |
| `backend/Code.gs` | โค้ดหลังบ้าน วางใน Apps Script (ไม่ได้ใช้บน GitHub) |

## ติดตั้ง (ทำครั้งเดียว)

### 1. ตั้งค่า Google Apps Script
1. เปิด Google Sheet ของระบบ → **ส่วนขยาย → Apps Script**
2. แทนที่โค้ดในไฟล์ `Code.gs` ด้วย `backend/Code.gs` ในโฟลเดอร์นี้ (ไฟล์ `Index.html` เดิมเก็บไว้ได้)
3. แก้ส่วน `PAYMENT` ด้านบนของ `Code.gs` เป็นข้อมูลจริง: ชื่อธนาคาร ชื่อบัญชี เลขบัญชี ชื่อพร้อมเพย์
4. เลือกฟังก์ชัน `setup` แล้วกด **Run** ครั้งเดียว (อนุญาตสิทธิ์ที่ขอ) ระบบจะ:
   - เพิ่มคอลัมน์ใหม่ `pets`, `payMethod`, `slipUrl` ในแท็บ Bookings (ข้อมูลเดิมไม่หาย)
   - สร้างห้อง 4 ห้องในแท็บ Rooms ถ้ายังว่าง
   - สร้างบัญชี `admin` / `admin1234` ถ้ายังไม่มี
5. ในแท็บ **Rooms** ใส่ราคาต่อคืน (`pricePerNight`) และจำนวนคนสูงสุด (`capacity`)
6. ในแท็บ **Users** ใส่อีเมลของแอดมิน เพื่อรับอีเมลแจ้งการจองใหม่และการยกเลิก

### 2. Deploy เป็น Web App
1. ใน Apps Script กด **Deploy → New deployment** → เลือกประเภท **Web app**
2. **Execute as:** Me · **Who has access:** Anyone
3. กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> ทุกครั้งที่แก้ `Code.gs` ต้องไปที่ **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy** ไม่อย่างนั้นเว็บจะยังใช้โค้ดเก่า (URL เดิมใช้ต่อได้)

### 3. เชื่อม LINE Official Account
ทำหลังข้อ 2 เพราะต้องใช้ Web app URL

1. **คัดลอก token:** [LINE Developers Console](https://developers.line.biz/console/) → เลือก Provider → Channel ของ OA (Messaging API) → แท็บ **Messaging API** → **Channel access token (long-lived)** กด Issue แล้วคัดลอก
2. **ใส่ค่าใน Apps Script:** **Project Settings (รูปเฟือง) → Script properties → Add script property** เพิ่ม 3 ค่า:

   | Property | ค่า |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | token จากข้อ 1 |
   | `LINE_REGISTER_CODE` | รหัสลับที่ตั้งเอง เช่น `km-4821` (ใช้ลงทะเบียนแอดมิน อย่าบอกคนอื่น) |
   | `ADMIN_PAGE_URL` | ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/admin.html` (ไม่บังคับ ใช้เป็นปุ่มในข้อความ LINE) |

3. **ตั้ง Webhook:** กลับไปแท็บ **Messaging API** ใน LINE Developers
   - **Webhook URL:** วาง Web app URL (ลงท้าย `/exec`) แล้วกด Update
   - เปิด **Use webhook**
   - ปุ่ม **Verify** อาจขึ้น error เพราะ Apps Script ตอบกลับแบบ redirect เป็นเรื่องปกติ ระบบยังรับข้อความได้
4. **ปิดข้อความตอบอัตโนมัติ (แนะนำ):** ใน [LINE Official Account Manager](https://manager.line.biz/) → **ตั้งค่าการตอบกลับ** ปิด "ข้อความตอบกลับอัตโนมัติ" และเปิด "Webhook"
5. **ลงทะเบียนแอดมิน:** แอดมินแต่ละคนแอดเพื่อน OA แล้วพิมพ์ในแชท
   ```
   แอดมิน km-4821
   ```
   (ใช้รหัสที่ตั้งไว้ในข้อ 2) ระบบจะตอบกลับว่าลงทะเบียนเรียบร้อย
   - อยากให้ทั้งทีมเห็นในกลุ่มเดียว: เชิญ OA เข้ากลุ่ม LINE (ต้องเปิด "อนุญาตให้บอทเข้าร่วมกลุ่มแชท" ใน LINE Developers ก่อน) แล้วพิมพ์คำสั่งเดียวกันในกลุ่ม
   - เลิกรับแจ้งเตือน: พิมพ์ `หยุดแจ้งเตือน`
   - ใส่รหัสผิด 5 ครั้งจะถูกพัก 1 ชั่วโมง
6. **ทดสอบ:** เข้าแดชบอร์ด กล่อง "เตือนกันลืม" จะแสดง "แจ้งเตือน LINE: เชื่อมแล้ว N ปลายทาง" กด **ทดสอบส่ง LINE**

ข้อความที่แอดมินจะได้รับทาง LINE:
- **การจองใหม่ รอตรวจสลิป** (สีเหลือง) พร้อมปุ่ม "ดูสลิป" และ "เปิดแดชบอร์ดเพื่ออนุมัติ"
- **ยกเลิกการจอง** (สีแดง) ทั้งลูกค้ายกเลิกเองและแอดมินยกเลิก
- **เตือนเช็คอิน** (สีน้ำเงิน) สรุปลูกค้าที่จะเช็คอินพรุ่งนี้ ส่งทุกเช้าเวลา 9:00 น. เมื่อเปิดสวิตช์ "ส่งอีเมลเตือนอัตโนมัติ" ในแดชบอร์ด

### 4. ตั้งค่าเว็บ
1. เปิด `js/config.js` แล้ววาง Web app URL แทน `PASTE_YOUR_WEB_APP_URL_HERE`
2. ถ้าเลขห้องในแท็บ Rooms ไม่ใช่ 1–4 ให้แก้ `ROOM_IMAGES` ให้ตรง
3. (ถ้ามี) วางรูป QR พร้อมเพย์ไว้ที่ `images/promptpay-qr.png` แล้วตั้ง `promptpayQrUrl: 'images/promptpay-qr.png'` ใน `Code.gs` (อย่าลืม Deploy เวอร์ชันใหม่)

### 5. ขึ้น GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดขึ้น repository (ให้ `index.html` อยู่ชั้นนอกสุด)
2. **Settings → Pages → Deploy from a branch → `main` / `(root)`** แล้ว Save
3. เข้า `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/login.html` ล็อกอินด้วย `admin` / `admin1234` แล้ว**เปลี่ยนรหัสผ่านทันที** (ผ่านหน้า Apps Script เดิม เมนู "เปลี่ยนรหัสผ่าน")

## ระบบทำงานอย่างไร

- **ลูกค้าจอง:** ปฏิทินดึงวันที่ไม่ว่างจริง เมื่อแนบสลิปและกด "แจ้งชำระเงิน" ระบบบันทึกการจองเป็น *รอยืนยัน* เก็บสลิปไว้ในโฟลเดอร์ Google Drive "Khun Mhee · สลิปการโอน" แล้วแจ้งแอดมินทาง LINE และอีเมล ระบบเช็คซ้ำก่อนบันทึก ถ้ามีคนจองตัดหน้า ลูกค้าจะเห็นข้อความให้เลือกวันใหม่
- **ลูกค้าตรวจสถานะ:** หน้ารออนุมัติมีปุ่ม "ตรวจสอบสถานะล่าสุด" (ใช้รหัสการจอง + เบอร์โทร)
- **แอดมินอนุมัติ:** กด "อนุมัติ" ในตาราง สถานะเปลี่ยนเป็นสีเขียว และลูกค้าที่ให้อีเมลไว้จะได้อีเมลยืนยัน
- **เตือนกันลืม:** สวิตช์ในแดชบอร์ดเปิดการเตือนอัตโนมัติทุกวันเวลา 9:00 น. (อีเมลถึงลูกค้า + LINE และอีเมลสรุปถึงแอดมิน) หรือกด "ส่งเตือน" รายคนก็ได้
- **ความปลอดภัย:** ข้อมูลลูกค้าเรียกได้เฉพาะเมื่อล็อกอินแล้ว (token หมดอายุใน 6 ชั่วโมง ใส่รหัสผิด 5 ครั้งล็อก 15 นาที) หน้าเว็บสาธารณะเห็นแค่วันที่ไม่ว่าง ไม่เห็นชื่อลูกค้า LINE token เก็บใน Script properties ไม่อยู่ในโค้ดหรือบน GitHub

## ข้อจำกัด
- LINE OA แพ็กเกจฟรีส่ง push message ได้จำนวนจำกัดต่อเดือน (ข้อความ 1 ฉบับนับต่อ 1 ปลายทาง: ส่งเข้ากลุ่ม 1 กลุ่มนับตามจำนวนสมาชิกในกลุ่ม) ตรวจโควตาได้ใน LINE Official Account Manager ถ้าโควตาหมด การจองยังบันทึกได้ปกติ แต่ข้อความ LINE จะไม่ถูกส่ง (ยังมีอีเมล)
- ลูกค้ายังได้รับแจ้งเตือนทางอีเมลเท่านั้น LINE ใช้แจ้งแอดมิน
- ระบบไม่ได้ตรวจสลิปอัตโนมัติ แอดมินต้องเปิดดูสลิปแล้วกดอนุมัติเอง
- Apps Script อ่าน header `X-Line-Signature` ไม่ได้ จึงตรวจลายเซ็น webhook ไม่ได้ ระบบใช้รหัสลงทะเบียนแทน และ webhook ทำได้แค่ลงทะเบียน/เลิกรับแจ้งเตือนเท่านั้น
- ข้อความบนหน้าเว็บที่ยังเป็นวงเล็บเหลี่ยม เช่น `[เวลา]`, `[เบอร์โทรศัพท์]`, `[ที่อยู่]` ในหน้าแรก ต้องแก้ใน `index.html`
